# Nova Geosfer VR

Türkiye odaklı bir rekreasyon rehberi. Bu sürüm klasik bir web sitesidir; VR katmanı sonraki adımda eklenecek.

## Çalıştırma

`index.html` dosyasını tarayıcıda açın. Sunucu gerekmez.

## İçerik

Aktiviteler `data.js` içindedir. Yeni rota eklemek için bu listeye bir nesne ekleyin.
